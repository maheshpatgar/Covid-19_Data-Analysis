# Global COVID-19 Analytics Dashboard | Power BI

## 📌 Overview
This project analyzes global COVID-19 data to identify trends, compare countries and continents, and highlight key pandemic insights through an interactive Power BI dashboard.

The project combines data cleaning, SQL-based analysis, and dashboard visualization to present meaningful KPIs and comparative trends.

---

## 🛠️ Tools & Technologies

- Python (Jupyter Notebook) – Data cleaning and preprocessing
- MySQL Workbench – Data analysis and querying
- Power BI – Dashboard creation and visualization
- DAX – KPI calculations and custom measures

---

## 🔄 Project Workflow

### 1. Data Cleaning (Python - Jupyter Notebook)
- Cleaned the raw COVID-19 dataset
- Handled missing and null values
- Standardized column names and formats
- Removed duplicates and inconsistent records
- Prepared the dataset for SQL analysis and Power BI visualization

### 2. SQL Analysis (MySQL Workbench)
- Identified the most affected countries
- Analyzed death, recovery, and active case trends
- Compared COVID-19 impact across continents
- Calculated death rate, recovery rate, and active case rate
- Generated insights for dashboard KPIs

### 3. Dashboard Development (Power BI)
- Created KPI cards for:
  - Total Cases
  - Total Deaths
  - Recovery Rate
  - Active Cases
- Built insight cards for:
  - Most Affected Country
  - Highest Death Rate Country
  - Highest Recovery Country
- Designed visualizations for:
  - Country-wise comparison
  - Continent-wise analysis
  - Death vs Recovery trends
  - Cases distribution
  - Top affected countries
---

## 📈 Key Insights

- The USA recorded the highest number of total COVID-19 cases.
- Vatican City had the highest death rate among all countries.
- Dominica showed the highest recovery rate.
- Asia and Europe were among the most affected continents.
- Recovery trends improved significantly in countries with better healthcare infrastructure.
